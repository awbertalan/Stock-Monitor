Stock Page Auto-Refresh Interval
How often the chart refreshes automatically when viewing a stock page. Set to Manual only to disable auto-refresh entirely. Takes effect on the next page load.
Trades List Limit
How many recent trades to display on the stock page (10–50). Takes effect on the next stock page load.
Update All Scope
The Update All button in the navigation bar only refreshes stocks whose instrument type and currency are both checked below.
The Update Everything button at the bottom refreshes all stocks regardless of this filter. Both skip the Delisted Instruments listed further down.

Auto-Update Schedule
Configure the automatic background update intervals for all stocks. Updates run in the background and refresh stock data from Millistream.
Update Performance
How many stocks to fetch from Millistream simultaneously. Applies to scheduled updates, manual updates, and both phases of an index-range Scrape. A full sweep of every instrument takes about 2h 30m with 1 worker and under 8 minutes with 16. The default of 10 matches what the live paper-trade engines already use.
Delisted Instruments
Instruments Millistream refuses with HTTP 403: expired warrants, certificates and derivatives, and delisted shares. Update All and Update Everything stop requesting one after repeated refusals. A refusal only counts if Millistream served another instrument after it in the same update. An expired token gets the identical 403, so a token or network problem cannot put healthy stocks on this list.

Trade Notifications
One notification per fill, sent by the engines as they trade — not by this page. A buy names the ticker, size, price, TP/SL and exit date; a sell adds the return, P&L and how long it was held. Queued during a run and sent only once the wallet has been written, so nothing is announced that a crash then rolls back.
Posted by osascript, so macOS attributes it to Script Editor — it must be allowed in System Settings → Notifications, or the banner is dropped with no error. Use Test below to check.
Subscribe to your topic in the ntfy app (iOS / Android) and pushes arrive anywhere. The topic name is the only credential — anyone who knows it can read your trades and push to your phone — so it lives in .env as NTFY_TOPIC and is never sent to this page.
ISIN Database
Update ISIN numbers for all stocks in the database. This will fetch and populate missing ISIN codes from Millistream. May take a minute or two.
Market List Database
Populate the market list (OMXS30, Large Cap, Mid Cap, Small Cap, First North, Spotlight) for every stock. Required for the dashboard list tabs to show data. Only fetches stocks with a missing list — safe to re-run.
